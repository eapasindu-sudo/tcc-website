# Thelijjawila Central College website

Website of MR/ Thelijjawila Central College (තෙලිජ්ජවිල මධ්‍ය විද්‍යාලය), Matara.

- `index.html`: the page itself
- `css/style.css` and `js/main.js`: styles and behaviour. **School events are listed at the top of `js/main.js`.**
- `js/loader.js` and `js/loader-art.js`: the loading screen (the line art draws itself, then colour is painted on)
- `assets/`: logo files. To add the school video, put it at `assets/school-video.mp4`.
- `data/posts.json`: Facebook posts shown in the News section, updated automatically
- `data/categories.json`: keywords and hashtags used to sort Facebook posts into categories

The site is published with GitHub Pages, and the Facebook news refreshes every 2 hours. See [SETUP-FACEBOOK.md](SETUP-FACEBOOK.md).
